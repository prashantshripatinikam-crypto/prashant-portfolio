# Replace placeholder artwork

Create one folder per project slug. Recommended files:

- `thumbnail.webp` — listing image, ideally 1600 × 1200
- `hero.webp` — case-study hero, ideally 2400 × 1350
- `mockup-01.webp`, `mockup-02.webp` — applications
- `process-01.webp` — sketches or process
- `campaign-01.webp` — advertising or social creative

Use AVIF or WebP where possible. Update `src/data/projects.js` and `ProjectVisual.jsx` when real artwork is ready.
